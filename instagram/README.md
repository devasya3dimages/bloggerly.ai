# Instagram carousels

Three 8-slide 4:5 (1080×1350) carousels for bloggerly.ai, each modelled on a reference from the Taste Sheet.

| Folder | Reference | Idea |
|---|---|---|
| `rules/` | IG-003 a16z (cream editorial, "X, Not Y" with diagrams) | Six Rules for Content That Actually Ships |
| `engine/` | T-006 Gabe Harris (dark-green tool stack, one slide per tool, poster CTA) | The 1-hour content engine. Comment BRIEF |
| `system/` | T-003 Matt Gray (editorial paper, worksheet slide as save trigger) | Your blog isn't a writing problem. It's a system problem. |

Edit the copy in `posts.html`, then run `node shoot.js` (Playwright) to re-export PNGs to `rules/`, `engine/` and `system/`.
